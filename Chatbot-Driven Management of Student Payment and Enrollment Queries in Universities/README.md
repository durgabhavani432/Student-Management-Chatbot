# Student Management Chatbot

A web-based chatbot designed to help university students get information about enrollment and tuition payment queries.

## Live Demo
[Click here to view the live project](https://student-management-chatbot-6.onrender.com)

## GitHub Repository
[Student Management Chatbot](https://github.com/durgabhavani432/Student-Management-Chatbot)

## Features
- Automated responses to student queries
- Enrollment-related information
- Tuition payment assistance
- User-friendly interface
- 24/7 chatbot support

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite / Database

## Project Description
This project provides an AI-based chatbot solution to simplify student communication by answering common questions related to university enrollment and tuition payments.

## Deployment
Deployed using Render.
